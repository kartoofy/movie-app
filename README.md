# Movie App 🎬

**Movie App** is a small React + Vite project that fetches and displays trending movies using data from TMDB’s free API. It also allows you to save your favorite movies locally in your browser.

## 🚀 Features
- 🔥 Fetch and display trending movies  
- ❤️ Add / remove movies from favorites  
- 💾 Persist favorites using `localStorage`  
- ⚡ Fast development setup with Vite  
- 📱 Clean and responsive UI  

## 🛠️ Built With
- React (Hooks like `useState` and `useEffect`)  
- Vite  
- CSS  

## 🎥 API Credit
Movie data provided by the free API from **:contentReference[oaicite:0]{index=0} (TMDB)**.  
This product uses the TMDB API but is not endorsed or certified by TMDB.

## 📌 About
This project was mainly created to practice core React concepts such as state management with `useState`, side effects with `useEffect`, and browser storage using `localStorage`. It’s part of my learning journey and mini-project collection.
